# Реализация NTRIP-шлюза на промышленном LTE-роутере БР-02 (OpenWrt)

Проект представляет собой архитектурное решение и программную реализацию **IP-моста/шлюза (NTRIP-клиента)** на базе индустриального роутера **БР-02** под управлением **OpenWrt**. 

При проектировании системы было учтено ключевое ограничение: **роутер не может выступать в роли полноценного RTK-ровера**. 
* ОС OpenWrt не является операционной системой реального времени (RTOS).
* Встроенный GNSS-модуль роутера имеет ограниченную точность.

**Выбранное решение:** Использование БР-02 в качестве прозрачного интеллектуального шлюза между внешним профессиональным GNSS-приёмником и базовой станцией (NTRIP-кастером).
